- index.html — существующий сайт, обновлённое меню и новые разделы.
- enhancements.css / enhancements.js — подбор автомобиля, реальные формы, отзывы,

- tests/test_workflows.py — автоматические тесты.
- publish.ps1 — публикация ТОЛЬКО публичного интерфейса на GitHub Pages.
- DEPLOY.md — инструкции по развёртыванию, безопасности и ограничениям.

ВАЖНО
Один GitHub Pages не может обрабатывать настоящие заявки, хранить общий список
заказов и защищать панель администратора. Для этих функций требуется запущенный
сервер backend и домен HTTPS. Пока API недоступен, клиентские формы сообщают об
ошибке, а не создают вымышленные «успешные» заявки.

На сайте нет заранее созданных настоящих отзывов, фальшивых заказов или цен
по неподтверждённым поколениям. Модели и поколения можно расширять через админку.

Чтобы развернуть сайт и API, изучите DEPLOY.md.

ПОДБОР АВТОМОБИЛЯ НА GITHUB PAGES (v3.1)
=======================================
На бесплатном GitHub Pages выбор марки, модели, поколения, просмотр возможных
направлений ремонта и запрос звонка/письма работают без бэкенда.
Для точной цены по конкретному поколению нужен подтверждённый прайс.
Каталог: vehicle-data.js (машины), price-data.js (цены, список offers изначально пуст).
Команда публикации: .\publish.ps1 в PowerShell из папки AvtoReyka46.
Подробнее: DEPLOY.md и CHANGELOG.md.
