АвтоРейка46 — публикация на GitHub Pages

1. Распакуйте архив в отдельную папку.
2. Установите Git for Windows и GitHub CLI (gh), если они ещё не установлены.
3. Откройте PowerShell в этой папке.
4. Выполните: .\publish.ps1
5. При первом запуске войдите в GitHub в открывшемся окне/браузере и подтвердите авторизацию.
6. Скрипт создаст публичный репозиторий и включит GitHub Pages. В конце покажет адрес сайта.

Важно:
- Это статический сайт. Данные профиля/форм, которые сохраняются только в браузере (localStorage/sessionStorage), не становятся общей базой данных и могут быть локальными для каждого устройства.
- GitHub Pages показывает сайт как обычную веб-страницу, поэтому JavaScript работает, в отличие от предпросмотра файла в облачном диске.
- Не размещайте на публичной странице пароли, персональные данные или секретные ключи.
