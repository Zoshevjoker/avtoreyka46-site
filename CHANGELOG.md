# Обновление 09.11.2026 — демонстрационный подбор v3.1

- Полностью заменён прежний список популярных марок на плотный алфавитный справочник со строкой поиска и выбором в три этапа; есть сброс/возврат по каждому шагу.
- Справочник расширен до **99 марок, 371 модели и 58 записей поколений**. Эти данные ориентировочные для навигации и не подтверждают работу техцентра с каждой машиной.
- Изображения девяти имевшихся брендовых логотипов извлечены в `assets/logos/` и работают офлайн; для остальных отображаются аккуратные текстовые монограммы, без чужих неподтверждённых логотипов.

- Бесплатный GitHub Pages работает без API; обновлён безопасный скрипт `publish.ps1`, добавлена инструкция редактирования справочника и цен.
- Серверный код для будущего этапа сохранён, но на GitHub Pages не публикуется. При подключении API также сможет отдавать брендовые изображения и файл цен.

# АвтоРейка46 — выполненные изменения

Версия: 2026-11-08. Основа: исходный `AvtoReyka46_GitHubPages.zip`.

## Сайт

- Сохранена исходная одностраничная архитектура и фирменная тёмно-зелёная палитра.
- Объединены материалы «О компании» и «Как работаем» в единую страницу; удалены лишние верхние пункты «Запись» и демонстрационные «Показатели цеха»; основные старые адреса перенаправляются в действующие разделы.
- В шапке отображается телефон компании с ссылкой `tel:`; нижние контакты сохранены.
- К блокам «Мы на других площадках» на главной и в услугах добавлены Яндекс Карты, сохранены ВКонтакте и Авито.
- Логотипы марок связаны с подбором, используются исходные прозрачные PNG.
- Добавлен пошаговый справочник марка → модель → поколение, отображение подтверждённой стоимости и заявка с автоматически выбранным автомобилем. Для неподтверждённых моделей и цен честно показывается запрос уточнения.
- Добавлены реальные отзывы с каруселью, свайпом, паузой при наведении и уважением предпочтений уменьшенной анимации. Вымышленные отзывы не загружены.
- Добавлены формы реальных заявок, оформления заказа товара, защищённого просмотра статуса и отзыва по одноразовой ссылке.
- Улучшены мобильные отступы, читаемость текста и фокус элементов управления.

## Сервер

- FastAPI + SQLite с централизованной базой, учётными записями по ролям и серверными сессиями.
- Роли `owner`, `admin`, `staff`; в публичной части нет демо-входов.
- Создание заявок, пошаговое подтверждение работ, дата визита, завершение/отмена, подтверждение выдачи товара и учёт остатков.
- Секретные ссылки отслеживания заказа и подтверждённого отзыва, ограниченные сроком действия; один заказ — один отзыв; перевыпуск ссылки.
- Модерация отзывов без изменения текста или рейтинга клиента; ответы компании.
- Создание, скрытие и редактирование марок/моделей/поколений, цены, сроки, доступность; массовый CSV-импорт.
- Настройки телефона и ссылок на внешние площадки; аудит административных действий.
- Данные SQLite хранятся отдельно от статического сайта; API не отдаёт наружу каталог `backend/` и другие закрытые файлы.

## Проверено

- `pytest`: два сквозных теста API, включая завершение услуги, публикацию отрицательного отзыва, выдачу товара, резервирование, повторную выдачу ссылки и сокрытие бренда.
- `node --check enhancements.js`: JavaScript синтаксически корректен.
- Chromium: 1440px и 390px, навигация, марки, процесс работы, экран входа, отсутствие ошибок JS при просмотре.

## Требуется перед публичным запуском

- Подтверждённые цены, типы реек по автомобилям, реальные товары/остатки и полный справочник поколений (в исходном архиве отсутствовали); массовый импорт готов.
- Подключение серверного API на HTTPS-домене или совместная публикация сайта и API на VPS. GitHub Pages сам по себе серверную часть не запускает.
- Отредактированные и утверждённые правовые документы оператора персональных данных и договор/оферта.
- При необходимости — согласованные API SMS/email для автоматической доставки ссылок. Сейчас отправка ссылок сотрудником выполняется вручную.
- Подтверждение ссылок на разделы отзывов Яндекс Карт и ВК (пока VK-review не задан, кнопка не показывается); ссылки редактируются в админ-панели.
