АВТОРЕЙКА46 — ДЕМОНСТРАЦИОННАЯ ВЕРСИЯ ДЛЯ GITHUB PAGES

Эта сборка специально показывает:
- марки автомобилей;
- примеры моделей и поколений;
- демонстрационную карточку предварительного подбора;
- примеры оформления отзывов (это НЕ реальные отзывы клиентов);
- примеры карточек каталога (это НЕ товары в наличии);
- описание направлений ремонта из материалов сайта.

Важные ограничения:
- совместимость конкретного автомобиля не подтверждается;
- цены, наличие и сроки не показываются как подтверждённые;
- заявки, резервы, отзывы, вход и администрирование отключены;
- сервер/API и база данных не входят в GitHub Pages сборку.

ПУБЛИКАЦИЯ:
Скопируйте index.html, config.js, enhancements.css, enhancements.js в корень репозитория,
заменив существующие файлы. Затем в PowerShell из папки репозитория:

git add index.html config.js enhancements.css enhancements.js
git commit -m "Improve AvtoReyka46 demo preview"
git push

После публикации обновите страницу сайта сочетанием Ctrl+F5.
