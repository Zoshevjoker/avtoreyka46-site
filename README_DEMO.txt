АВТОРЕЙКА46 — ДЕМОНСТРАЦИОННАЯ ВЕРСИЯ ДЛЯ GITHUB PAGES

Содержимое:
- index.html
- config.js
- enhancements.css
- enhancements.js

ЧТО РАБОТАЕТ
- Публичные страницы и навигация.
- Оформление и клиентские интерактивные элементы, не требующие сервера.
- Ссылки между разделами.

ЧТО ОТКЛЮЧЕНО
- Отправка заявок и резервов.
- Регистрация, вход сотрудников и административные действия.
- Отправка отзывов и отслеживание заявок.
- Получение реального справочника автомобилей, каталога и отзывов из API.

На сайте размещено заметное предупреждение о демонстрационном режиме. При попытке выполнить серверное действие сайт показывает сообщение, что действие не отправлено. Успешные заявки и отзывы не имитируются.

ПУБЛИКАЦИЯ В УЖЕ СУЩЕСТВУЮЩИЙ GITHUB PAGES
1. Распакуйте архив в папку локального репозитория, где сейчас лежит index.html.
   Согласитесь на замену файлов.
2. Откройте PowerShell в этой папке.
3. Выполните:

   git status
   git add index.html config.js enhancements.css enhancements.js
   git commit -m "Publish AvtoReyka46 demo version"
   git push

4. Дождитесь завершения GitHub Pages и обновите сайт с Ctrl+F5.

ВАЖНО
Не загружайте backend, базу SQLite, тесты, пароли, токены или служебные файлы на GitHub Pages.
Это демонстрационная сборка, не предназначенная для приёма настоящих персональных данных.
